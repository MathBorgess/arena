# Shared API contract

`new Arena(databasePath)` (export from `src/arena.ts`) owns migrations, durable SQLite state and synchronous transactions. `arena.bootstrap({workspace_name, owner_name})` returns `BootstrapResult` once per new database; repeated init refuses to reset credentials. `arena.authenticate(token)` looks up a hashed token and returns the persisted actor. `arena.execute(operation, actor, input)` is the shared public boundary; all references, memberships and permissions are checked here. `close()` closes SQLite. `src/contracts.ts` is transport vocabulary, not domain state.

All requests use snake_case JSON. Every mutation takes `workspace_id` and `idempotency_key`; an existing aggregate additionally takes `expected_revision` (branch current revision, profile base revision, source revision or member revision). Human approval additionally takes `expected_head_revision` and `presented_version` (proposal.version). Response fields below are fixed for independently developed transports. Unknown fields such as actor/kind/role must never grant permissions.

## Agent operations

- `arena.list_work`: workspace_id, optional query/cursor/limit. Returns `{explorations:[{id,title,objective,branches:[{id,name,current_revision_id,profile_revision_id}]}],next_cursor}`. Query matches related title/objective/dimensions; opaque cursor pins the results snapshot.
- `arena.read_context`: branch_id, optional revision_id/cursor/limit. Returns `{format_version:1,workspace_id,exploration:{id,title,objective},branch:{id,name,origin_branch_id,origin_revision_id,current_revision_id,profile_revision_id},revision:{id,fields,locks,artifacts,profile_revision_id},profile,proposals,decisions,feedback,sources,sessions,open_questions,next_action,next_cursor}`. Revision IDs stay fixed during pagination. Source content only through read_source; revoked content must not leak through proposals, decisions, artifact text, historic snapshots or exports.
- `arena.read_source`: source_id, offset/limit. Returns `{id,revision,content,origin,author,date,rights,usage_scope,coverage,next_offset}`; only active, permitted sources can be read.
- `arena.create_exploration`: title, objective, optional profile_revision_id. Returns `{exploration_id,branch_id,revision_id}` with empty fields and independent initial branch.
- `arena.create_branch`: source_branch_id, source_revision_id, expected_revision (=source head), name, vary_dimensions, optional locks. Returns `{branch_id,revision_id}`; inherits the pinned profile, locks and accepted artifacts, stores exact origin. Variation does not itself alter accepted content.
- `arena.submit_proposal`: branch_id, base_revision_id, expected_revision (=head), changes object mapping dimensions to text, dependencies object mapping changed dimension to upstream dimension array (absent means conservative), rationale, source_ids, optional warnings and session_metadata `{provider,client_name,client_version?,external_session_id?}`. Session metadata is a declaration; the server records the authenticated actor, exact input revision and canonical Arena session ID. It never grants permissions or establishes native provider verification. Returns `{proposal_id,version,status:'pending'}`. All source IDs and dependency names are checked; no client-supplied actor.
- `arena.add_feedback`: branch_id, target_id (branch/proposal), revision_id, expected_revision, text, type (`critique`/`question`/`comment`). Returns `{feedback_id}`; never approves.
- `arena.compare_branches`: left_branch_id,left_revision_id,right_branch_id,right_revision_id, optional criteria. Returns `{left,right,common_base,differences:[{dimension,left,right}],locks,needs_review,criteria}` deterministically.
- `arena.propose_profile_change`: profile_revision_id, expected_revision (=profile_revision_id), changes, evidence_source_ids, rationale. Returns `{proposal_id,version,status}` without changing voice.
- `arena.export_context`: branch_id, revision_id. Returns `{package: <read_context plus relevant rejections and source metadata>,markdown,checksum}`. Validates current permissions; historical package is data, not authorization.
- `arena.get_operation`: workspace_id,idempotency_key. Returns `{found,result?}` scoped to authenticated actor.
- `arena.list_profiles`: workspace_id. Returns `{profiles:[{id,name,current_revision_id,revisions:[{id,version,content}]}],proposals}`. Voice proposals expose their exact ID, base revision, version, changes, evidence, rationale and status for human comparison before approval; current source restrictions apply to both arrays.

## Human operations

- `human.create_profile`: name, content `{identity,objectives,tone,vocabulary,positive_examples,negative_examples,rules}`, source_ids. Returns `{profile_id,profile_revision_id}`; initial human-authored approved immutable version.
- `human.decide_proposal`: proposal_id, expected_revision and expected_head_revision (=branch head), presented_version, decision (`accepted`/`rejected`/`deferred`/`superseded`), optional comment, optional selected_dimensions. Returns `{decision_id,revision_id?,proposal_id,derived_proposal_id?}`. Partial acceptance creates and accepts a derived proposal with chosen subset; records origin and retains unselected suggestion.
- `human.edit_branch`: branch_id,expected_revision,changes,dependencies,source_ids,reason. Returns `{revision_id}`. Cannot silently break locks.
- `human.set_locks`: branch_id,expected_revision,locks (dimension→current value),reason. Returns `{revision_id}`. Explicit human action can remove existing locks.
- `human.approve_profile`: proposal_id,presented_version,expected_revision (=current voice head),comment. Returns `{profile_revision_id,decision_id}`. Old branches stay pinned.
- `human.import_sources`: format (`json`/`csv`), content (file text), origin,rights,usage_scope,coverage. JSON is an array of `{text,origin?,author?,date?,rights?,usage_scope?,coverage?}`. CSV has a `text` column and optional same metadata columns. Returns `{source_ids,integration}`. No scraping, no native API claim.
- `human.list_sources`: workspace_id. Returns `{sources:[{id,revision,status,origin,author,date,rights,usage_scope,coverage}]}`; no contents.
- `human.revoke_source` / `human.remove_source`: source_id,expected_revision,reason. Returns `{source_id,status,revision}`. Revocation blocks reads/export and marks derived artifacts; removal erases original and controlled source-derived text while retaining minimal audit metadata. It cannot retract externally exported copies.
- `human.invite_member`: name,kind (`human`/`agent`),role (`editor`/`reviewer`), expected_revision (=workspace membership revision). Returns `{actor,token,member_revision,workspace_revision}`. Owner-only; credentials displayed once by CLI/UI, never in context or logs. Agent-kind cannot approve.
- `human.revoke_member`: member_id,expected_revision (=member revision),reason. Returns `{member_id,revision}`; owner-only; authenticate/use after revocation fails.
- `human.integration_status`: workspace_id. Returns `{integrations:[{provider,account,state,capabilities,scopes,last_verified,limitations,pagination,costs,unavailable_reason}]}`. Social native APIs unavailable; export importer accurately reports tested export path; native client configured/authenticated/read verified/operation tested remain distinct and never inferred from SDK fixtures.
- `human.record_verification`: provider (`codex`/`chatgpt`),expected_revision (adapter record revision),stage,evidence. Returns adapter status. Explicit owner attestation only, never automatic provider claim.
- `human.review_artifacts`: branch_id,expected_revision,dimensions,reason. Returns `{revision_id}`; explicit reuse after invalidation, checks source permissions.
- `human.export_text`: branch_id,revision_id. Returns `{text,status:'exported',revision_id}`; refuses unreviewed artifacts. Does not publish. No approved text inferred from pending proposals.

## State semantics

`revision.fields` maps all dimensions to strings. `revision.locks` maps locked dimensions to exact values. `revision.artifacts` maps present dimension to `{content,dependencies,source_ids,needs_review,input_revision_id,author}`. Changes invalidate existing transitive dependents; unknown dependency edges invalidate conservatively. Voice qualitative rules return warnings, never assert perfect fidelity. Provenance is recorded for each accepted content artifact. Decisions and feedback have authenticated author and timestamp. Text gets revised through explicit decisions; export status is a separate event, publication is absent.

Cross-workspace or unauthorized IDs return NOT_FOUND without revealing existence. Idempotency lookup requires current authorization and returns only sanitized prior responses; do not retain/replay invite tokens. All mutations and audit records commit in one SQLite transaction. Same actor/key/target/arguments replay the result; changed arguments return IDEMPOTENCY_CONFLICT. Concurrent proposals may coexist; acceptance requires unchanged presented base/head and returns REVISION_CONFLICT without losing proposals.

## Artifact interaction extension

The user has redirected presentation to a compact artifact viewer, with all conversation in the harness; see ADRs 0002 and 0003. Existing domain operations remain shared.

- `arena.open_artifact`: branch_id, optional revision_id, proposal_id and presented_version. Returns exact authorized context plus `artifact:{branch_id,revision_id,current_revision_id,kind,text,proposal_id?,presented_version?,source_ids,redacted?}`. Default selects the latest pending text proposal, otherwise accepted text. Explicit revision_id selects that accepted snapshot; explicit proposal_id selects its pending version and exact base (an optional revision_id must match the base). `revision_id` in the artifact is the displayed base, while current_revision_id is the current CAS head. The branch-only fallback URL follows new proposals/head; only explicitly selected revision/proposal references pin the URL. `presentation.follow_current` distinguishes these modes. Negotiate MCP Apps extension before claiming embedded rendering; expose useful structured output in every client. No tokens in the returned viewer location.
- `arena.read_events`: workspace_id,branch_id, optional cursor/limit and since_cursor. Returns `{events,next_cursor,event_cursor,current_revision_id}`. cursor/next_cursor iterate a pinned page snapshot; pass event_cursor as since_cursor on a subsequent read to retrieve newly persisted events. Events identify the artifact, exact revision, authenticated author, timestamp, typed action and optional validated passage selection. Recheck permissions and redact revoked source-derived text on every read.
- `arena.record_interaction`: same selection/selection_clear/comment/request_revision payload as the human interaction command below, but authenticated as the delegated agent. Persist that actor plus an unverified UI-origin hint; never claim human authorship or mutate accepted state. It is safe for embedded widgets to call this operation and then update model context.
- `human.record_artifact_interaction`: workspace_id,branch_id,revision_id,expected_revision,idempotency_key,type (`selection`/`selection_clear`/`comment`/`request_revision`), dimension, optional proposal_id and presented_version, optional selection `{start,end,text}` or null, optional comment. Proposal selections must match a currently pending text proposal, exact presented version and base. Selection reference events can point to an authorized historical revision while expected_revision still checks the current branch head; they never authorize an accepted write. `selection_clear` stores null without a passage or comment and remains possible after source restriction changes. Returns `{event_id,revision_id}`. Only an authenticated human channel can attribute it to a person; validate offsets against the exact referenced text. A selection/comment does not approve a proposal or implicitly change the voice profile.

## Transport and viewer

MCP exposes agent operations and the artifact read/event extensions. Authentication is independently scoped; identity never comes from tool arguments. Tool results include structured actionable errors. Stdio stdout contains protocol only. Native-client examples do not change the user's own configuration.

The preferred visual surface in a verified MCP Apps-capable host is a `ui://` resource linked from the artifact tool. The read-only component receives tool results, refreshes current proposals, and automatically persists native cursor selections and selection_clear through an authenticated channel. It displays only text; IDs, versions, offsets and author remain in durable context. It supplies a compact context snapshot through `updateModelContext` when supported, while persistent events keep the complete history. The host may apply the update only at the next user message. Selection never calls sendMessage or requests an agent turn; all requests and workflow commands stay in conversation and the companion skill.

A plugin packages MCP, companion skill and viewer resources in the selected client's format. It cannot guarantee embedded UI in a client that only supports tools. Keep actual client verification separate from SDK/reference-host tests.

The local compatibility viewer binds `127.0.0.1` only and displays only the selected read-only text and native cursor selection; there is no chat or standalone editorial platform. It uses `/api/login` with a human token to establish an HttpOnly SameSite=Strict session, `/api/call` with `{operation,input}`, `/api/session` for authenticated non-secret session metadata, and `/api/logout`. State changes check the exact Origin; static assets use a restrictive CSP. Domain serialization uses ArenaError.toJSON(). MCP Apps app-only visibility must not bypass human session authorization.

The minimal viewer polls both current and explicitly pinned historical artifacts against current permissions. An unchanged exact text preserves its native selection; a changed artifact clears the prior selection automatically. Restricted text and context are cleared even at historical URLs. Setup authentication and transient errors are the only extra visual surfaces. Human decisions use the independently authenticated CLI channel described by ADR 0003, never a button or MCP agent credential.
