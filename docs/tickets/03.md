# 03: Read-only proposal viewer with automatic selection context

Issue: https://github.com/MathBorgess/arena/issues/4

**Status:** implemented — pending final review and PR merge

Parent: https://github.com/MathBorgess/arena/issues/1

The latest owner direction supersedes the previous editing/review UI; see ADR 0003. Show only the current proposal text in a read-only native selectable surface. All requests, messages and workflow remain in the harness and companion skill.

## Acceptance criteria

- [x] Display the latest pending text proposal, otherwise accepted text, with exact proposal/version/base metadata outside the visual text.
- [x] Automatically persist native cursor selections with UTF16 offsets and authenticated authorship. Empty selection persists selection_clear and clears prior context.
- [x] Embedded MCP Apps updates model context automatically where offered; selection never sends a message or starts a turn. The local fallback supplies events for the next conversation.
- [x] Remove editing, comments, review buttons, navigation, source/voice drawers, comparisons and exports from the viewer. Preserve these domain operations for conversational commands.
- [x] Refresh new persisted proposals; preserve an unchanged native selection and reasonable scroll position. Default URLs follow the current artifact; explicit revision/proposal URLs retain exact references.
- [x] Apply current restrictions to every refresh, including pinned historical snapshots, clearing controlled text and selection/model context.
- [x] Verify SQLite/HTTP and MCP Apps SDK reference-host paths without claiming actual Codex/ChatGPT compatibility.

## Evidence

- New public API/MCP red→green slices verify proposal text selection, exact base/version, wrong versions/offsets/head, source restrictions and empty-selection clearing.
- Browser boundaries: native cursor selection and clearing in the local readonly viewer; new-proposal refresh and same-text selection retention; exact historical URL with external source removal; a real MCP client/server bridged by SDK AppBridge with automatic model context and zero messages; embedded revocation clears both controlled text and the last context snapshot.
- Setup authentication remains separate and temporary. The authenticated normal surface contains only one readonly textarea and no buttons, navigation or drawers. HTML-shaped content is assigned as literal textarea value.
- Original standards findings are addressed: historical polling always rechecks current source restrictions; explicit revision_id/proposal_id/presented_version URL metadata is honored. New default MCP fallback links no longer freeze the initial head.
- Run `npm run check`, `npm test`, `npm run build` and `npm run test:ui`. The root report records final integrated counts.
- Native Codex/ChatGPT rendering and cross-client execution remain pending; SDK/reference-host evidence is technical verification only.
