## What to build

Show the current artifact alongside the user's existing agent conversation. A compact Portuguese viewer provides selection, feedback, editing and comparison; relevant interactions become durable context readable through MCP. Package it with the MCP and companion skill, preserving the harness as the only conversational surface.

## Acceptance criteria

- [ ] MCP Apps-capable hosts render the artifact through a UI resource; compatibility is negotiated and reported accurately.
- [ ] Unsupported hosts can open a compact local viewer of the same artifact; no separate chat or editorial platform is introduced.
- [ ] Show text, proposed changes, exact revisions and branch differences; allow selecting a passage, attaching a comment, editing and accepting chosen changes through authenticated human actions.
- [ ] Persist relevant interactions as typed events with artifact/revision/selection/authorship, retrievable by the agent through MCP.
- [ ] Update model context in supporting hosts; distinguish context refresh from an explicit request to continue working.
- [ ] Keep voice, locks, sources, stale dependencies and export controls accessible within the artifact workflow.
- [ ] Keyboard accessible UI; render source text safely. Verify the interaction→persistent event→agent context path at the confirmed seam, separately from actual harness compatibility.
