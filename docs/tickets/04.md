## What to build

Scoped native MCP clients and CLI setup: observable textual Arena v1 behavior following the recorded specification and shared contract.

## Acceptance criteria

- [x] Expose the specified arena tools and artifact/event readers using the real MCP SDK with scoped agent credentials.
- [x] Package the companion skill, MCP and artifact viewer in the selected client plugin format; report negotiated UI support and provide a compact local fallback when necessary.
- [x] No agent tool inherits human decisions; authenticate every call and serialize actionable errors.
- [x] CLI initializes local private data and separately provisions agent identities.
- [x] SDK transport tests verify discovery, persistence, context handoff and permission revocation.
- [x] Document actual native Codex/ChatGPT setup without changing user configuration or claiming fixture equivalence.

## Validation evidence

Five real SDK protocol tests exercise scoped discovery, bounded typed input contracts, independent agent authentication, direct structured/text results, actionable validation/domain errors, declared session provenance, advertised MCP Apps capability, a self-contained UI resource, agent-attributed selections, incremental event checkpoints, exact-revision fallback locations, authenticated stateless HTTP and permission revocation on established transports. Human methods are not registered. Tests use SQLite through the shared public domain, not internal tables.

Five CLI subprocess tests verify private durable setup, refusal to reset credentials, an independent human viewer alongside agent HTTP, persistence/idempotency across SDK stdio processes, distinct named agent identities, and refusal of a human credential file for MCP. Token values never appear in CLI stdout or fixture logs; only private-file paths are printed. The CLI reads membership revision live before provisioning. Source clients are SDK fixtures, not native provider sessions.

Red→green slices began with missing MCP/CLI modules, missing resource linkage, unavailable stdio/serve/named-agent commands, a fallback missing its exact revision, and schema failures without an actionable structured envelope. Named-agent setup became green after its real domain dependency landed; unsupported operations were never faked. Native Codex/ChatGPT setup and the optional remote prerequisites are documented in `docs/mcp-clients.md`. Installation, account authorization, native execution and embedded rendering in the owner's clients remain unverified; no owner configuration or tunnel was changed.

`npm run check`, `npm run build`, all 30 current Node tests and the two current Playwright browser checks pass on the ticket branch. The browser checks are the local authenticated viewer and SDK reference host; they do not prove native host compatibility.
