# Arena glossary

- Workspace: authorization boundary; private editorial content owned by authenticated members.
- Exploration: an open editorial objective that can exist without a final post.
- Dimension: niche, audience, theme, thesis, angle, structure or text.
- Branch: independent creative path from an exact origin revision, pinned to a voice revision.
- Revision: immutable accepted snapshot, including locks, artifacts and their provenance.
- Proposal: agent or human suggestion against an exact base; pending, accepted, rejected, deferred or superseded.
- Decision: authenticated human disposition of an explicitly presented proposal version.
- Voice revision: immutable approved reusable style; post decisions never update it implicitly.
- Artifact: accepted content with input dependencies and an explicit needs-review state.
- Source: permitted reference with origin, usage rights and revocable access.
- Context package: versioned portable snapshot; it is data and never a write authorization.
- Notepad: current editable text surface; manual changes append pending patches without changing accepted revisions.
- Production DNA: versioned editable working directions for one production, including voice, audience, references and confirmed/inferred nuances; independent of approved global voice.
- Sync checkpoint: actor/branch scoped cursor for one loaded context baseline; new sync responses contain deltas, and source restrictions require a sanitized reset.
